Ziplex · internal reference

지금 Ziplex에 뭐가 있나

9개 갈래로 나눈 전체 기능 지도. 각 가지를 펼치면 그 안의 개별 기능과 상태 태그가 나옵니다 — 뭐가 단단한 땅이고 뭐가 아직 무른 땅인지 한눈에 보려고 만든 문서예요.

안정 충분히 테스트됨, 실사용 검증됨
부분 구현 동작은 하지만 알려진 한계가 있음
공백 아직 손 안 댐, 필요성만 확인된 상태
보류 검토 후 의도적으로 안 만들기로 함
▸ PIPELINE 핵심 파이프라인 — pack 안정
1. 파일 수집 file/collector.py 안정

DEFAULT_IGNORE + 프로젝트의 .gitignore + .ziplex.json의 include/ignore를 합쳐서 스캔 대상을 정함. 바이너리 파일은 내용 기반으로 자동 제외.

2. 보안 스캔 file/scanner.py 부분 구현

secretlint 우선, 실패 시 정규식 폴백. 위험 파일은 사유·매칭 라인과 함께 보여주고 개별 승인 가능. Windows에서 secretlint 자체가 잘 안 붙는 알려진 이슈 있음 — 정규식 폴백이 사실상 기본 경로.

3. 파일 선택 file/selector.py 안정

대화형 / --auto(전체) / GUI 체크박스 / preselected(외부 지정) 네 경로가 전부 동일한 후보 목록을 공유.

4. 구조 추출 + 압축 extract/code/* 안정

Tree-sitter로 시그니처·의존성·API 라우트 추출, 함수 본문은 마커 하나로 압축. 13개 언어 지원 (아래 LANGUAGES 참고).

5. 비-코드 텍스트 압축 extract/text/* 안정

JSON/Markdown/일반 텍스트 전용 압축기. Markdown 안의 코드 블록은 언어 태그로 위 코드 압축기를 재사용.

6. LLM 요약 llm.py · summarizer.py 안정

Gemini가 기본값이지만 OpenAI 호환 엔드포인트(Ollama·LM Studio 등 로컬 서버 포함)나 Claude로도 전환 가능(LLM_PROVIDER 또는 GUI Options). 파일 여러 개를 한 프롬프트로 묶는 배치 처리로 429/503 부담을 줄이고, 모든 REST 호출에 타임아웃을 걸어 네트워크가 막혀도 무한 대기하지 않음. --no-llm이면 시그니처만으로 만든 구조적 요약으로 완전 대체.

7. 사람 검토 corrector.py · edits.py 안정

confidence 낮은 요약만 검토 프롬프트에 올라옴 — 나머지는 자동 유지, 그래도 손으로 고칠 순 있음.

8. 저장 packager.py 안정

aif.json(요약+관계, 항상 로드) / detail.json(압축 본문, 필요시) / cache.json(해시, 내부용) 세 파일로 분리 저장.

▸ RESILIENCE 신뢰성 · 복원력 안정
체크포인트 저장/재개 checkpoint.py 안정

LLM 호출이 반복 실패하면 그 시점까지 결과를 저장하고 중단. 다음 pack에서 자동 발견해 이어서 진행. 경로 해시로 이름 같은 다른 프로젝트끼리 안 섞임.

Incremental re-pack freshness.py 안정

내용 해시가 그대로인 파일은 이전 요약을 그대로 재사용 — 바뀐 파일만 LLM 호출.

Freshness 감지 freshness.py 안정

해시 비교만으로 "이 pack이 디스크 상태랑 얼마나 어긋났나" 확인. LLM 호출 없음, CLI/MCP/GUI 배지 전부 이걸 공유.

GUI 작업 취소/재개 gui/pack_service.py 안정

백그라운드로 도는 pack 작업을 "저장 후 취소"하면 위 체크포인트와 같은 방식으로 다음 실행에 자동 이어짐.

▸ SIGNALS 품질 · 투명성 신호 안정
confidence 점수 confidence.py 부분 구현

요약 단어와 실제 시그니처의 겹침을 보는 휴리스틱. 0.34 미만이면 검토 대상. 시그니처가 적은 파일(필드 초기화가 로직인 클래스 등)은 구조적으로 낮게 나올 수 있음 — 정답 검증기는 아님.

tech_stack 감지 tech_stack.py 안정

package.json/requirements.txt 등 매니페스트 8종을 직접 파싱. LLM 호출 없이 "실제로 뭘 의존한다고 선언했나"만 뽑음.

security_scan project.security_scan 안정

이번 pack에서 몇 개가 걸렸고, 몇 개가 승인됐고, 몇 개가 빠졌는지 project에 기록. aif.json만 따로 봐도 "이거 스캔은 됐나"를 알 수 있게.

format_notes project.format_notes 안정

aif.json이 이 프로젝트 문서 하나 없이 단독으로 다른 사람/AI에게 넘어가도, 마커·confidence 의미를 스스로 설명하는 고정 문구.

▸ GRAPH 관계 그래프 안정
의존성 그래프 연산 file/relationship.py 안정

internal/external 분리, build_tree · move_file · has_cycle · get_dependents · get_blast_radius. GUI 편집기와 corrector.py가 같이 씀.

텍스트 참조 매칭 text_references.py 부분 구현

Tree-sitter 문법이 없는 파일(Godot 씬, README)도 실제 파일명 언급을 찾아 관계에 편입 — 무료, LLM 없음. 산문 언급과 구조적 참조를 구분 못 함(둘 다 그냥 dependencies에 섞임).

▸ CHANNELS 결과물 소비 경로 — 3가지 안정
MCP 서버 mcp_server.py 안정

읽기 전용 툴 8개. Claude Code/Cursor 등에서 aif.json을 복붙 없이 바로 질의. get_dependents/get_blast_radius는 사람이 보정한 그래프 위에서 동작.

로컬 GUI gui/ 안정

pack부터 browse까지. 127.0.0.1 전용, 서버·계정·외부 전송 없음. Claude Code를 못 쓰는 환경(폐쇄망 등)을 위한 경로.

Claude Agent Skill export skill_export.py 안정

.claude/skills/ 아래에 정적으로 놓아두면 서버 없이 Claude Code가 알아서 인식. 원본 소스는 절대 안 실음.

▸ CONFIG 설정 계층 — 2단 안정
.ziplex.json config.py 안정

대상 프로젝트별 include/ignore. 그 프로젝트 저장소에 커밋하는 용도 — Ziplex 자체 저장소가 아님.

~/.ziplex/settings.json settings.py 안정

사용자별 — 기본 출력 폴더(전역+프로젝트별 고정), AI 프로바이더 선택(Gemini/OpenAI 호환/Claude)과 각각의 키·모델·base URL(GUI Options에서 입력, Ollama/LM Studio는 원클릭 프리셋 제공).

▸ CLI 명령어 전체 안정
pack · init

전체 파이프라인 / .ziplex.json 스캐폴딩.

collect · tokens · tree · search

pack 없이 미리보기 — 수집만 / 토큰 카운트만 / 의존성 트리만 / 정규식 검색.

detail · freshness · skill

detail.json 부분 읽기 / stale 여부 확인 / Claude Skill로 내보내기.

select · analyze

대화형 파일 선택만 / LLM 분석만 (요약+룰+가이드, 압축·저장 없음).

signatures · dependencies · api · compress · debug

단일 파일에 대해 추출 단계 하나만 실행 — 디버깅용.

▸ TEAM / CI 팀 작업 · 자동화 부분 구현
git 커밋 컨벤션 부분 구현

aif.json/detail.json/cache.json을 프로젝트 저장소에 커밋해서 팀이 공유 — README에 문서화된 권장 방식.

--max-tokens CI 가드 안정

패킹 결과가 정해둔 토큰 예산을 넘으면 빌드 실패 처리.

머지 충돌 대응 부분 구현

여전히 "누구 게 맞는지" Ziplex가 정하진 않지만, 문서화된 해결법(충돌 해소 → 재pack → 검토)과 GitHub PR diff를 접어주는 .gitattributes 템플릿이 생김 (docs/team/).

push 시 자동 재pack 안정

자동 재pack 대신 detection-only 게이트로 방향 전환 — ziplex freshness가 drift 시 exit 1, GitHub Actions 템플릿(docs/ci/freshness-gate.yml) 제공. 재pack 자체는 LLM 비용·리뷰 생략 리스크 때문에 의도적으로 자동화하지 않음.

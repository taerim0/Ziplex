# src/ziplex/ — pack pipeline, exports, query layer, config

Modules directly under `src/ziplex/*.py`. The graph engine is in `core/` (`src/ziplex/core/AGENTS.md`), the optional LLM layer in `enrich/` (below), file collection/scanning in `file/`, extraction in `extract/`, the read-only viewer in `gui/`. History behind any of this: `docs/HISTORY.md` (never auto-loaded).

## `packager.py` — `pack()` / `save_aif()`

`pack(root_path, use_cache=True, use_llm=True, include=None, ignore=None, result_dir=None, lang="en", progress_lang="ko")` returns a finalized in-memory aif (relationships built via `file/relationship.build_tree()`), or `{}` when nothing is left to pack. Always non-interactive (`auto`/`interactive` kwargs are accepted from old callers and ignored). Flow: `_select_files()` (collect → secret scan) → previous summaries by content hash (`freshness.load_previous_summaries()`; failure placeholders and, in LLM mode, structural summaries are dropped so they regenerate) → one `core.graph.GraphBuilder` → per-file `extract_all()` + resolved deps + text refs → summaries (`enrich.summarizer.generate_summaries()` or `generate_structural_summaries()`) → rules / AI guide (one attempt each; failure → `[]` / `STRUCTURAL_ONLY_NOTE`) → structural folder summaries → flagged files added graph-only (`_graph_only_entries()`: imports + `FLAGGED_SUMMARY`, never content; `.ziplex.json` `exclude_flagged_from_graph` drops them) → token counts → `_assemble_aif()`.

`_SummaryCache` (`<project>/.ziplex/summaries.json`, gitignored by `core.index.ensure_gitignore()`) stores LLM summaries keyed by `lang:content-hash`, flushed every 8 results and in a `finally`, so an interrupted pack keeps what it paid for. It replaced checkpoint/resume.

`save_aif()` writes aif.json (no `compressed`; certain edges only), `<name>.detail.json` (`{file: {compressed, text_refs?}}`) and `<name>.cache.json` (`{file: hash}` manifest); `_measure_saved_tokens()` overwrites `tokens.*.compressed` with the saved file's own size. `project.ziplex_version`/`project.llm` let `cli._up_to_date_pack()` skip a repeat `pack --auto` when nothing changed.

## `enrich/` — optional LLM layer (`pip install "ziplex[llm]"`)

`enrich/llm.py`: providers (`GeminiProvider` default, `OpenAIProvider` for any Chat-Completions endpoint incl. Ollama/LM Studio, `ClaudeProvider`, `MockProvider` for tests), resolved fresh per call (constructor arg → `settings.py` → env → default; an explicit `LLM_PROVIDER` env var wins over a stored setting). `requests`/`python-dotenv` are imported optionally — the module loads without them and `_post()` raises `MISSING_EXTRA_MESSAGE`; `cli._cmd_pack` checks first. Retries 429/5xx/transport errors with capped backoff, a half-open circuit breaker per pack, `request_timeout()` scaled by prompt size, Gemini `thinkingBudget: 0`. Every `analyze_*()` asks for JSON only and takes `lang` (value in that language, keys English); callers `json.loads()` and fall back to a default. `usage_tracker` (`reset_usage()`/`get_usage()`) records billed tokens per pack.

`enrich/summarizer.py`: batched summaries (`BATCH_SIZE` per prompt, `MAX_WORKERS` threads, submits via `contextvars.copy_context().run` so the progress language carries into workers), per-file fallback for names a batch missed, a probe that stops hammering an exhausted provider, `on_result` callback per real summary (the summary cache). Prompts use `core.graph.code_dependencies_of()` (imports only) and the file's leading doc comment. `generate_structural_summaries()` is the no-LLM counterpart; `SUMMARY_FAILED_PLACEHOLDERS`/`is_summary_failed_placeholder()` mark failures in any language.

## Exports and the aif.json query layer

- **`aif_io.py`** — the disk boundary for `relationships`: in memory each entry is `{internal, external, internal_text_refs}`; on disk aif.json keeps certain edges only and prose mentions move to detail.json `text_refs` (`detach_weak_edges()` on write, `attach_weak_edges()` on read). `dumps_aif()`/`write_aif()` own the one-entry-per-line layout every writer uses.
- **`query_service.py`** — read-only queries over a saved aif.json (overview, files, folders, relationships, graph summary, dependents, blast radius, detail, freshness, search), memoized on (mtime, size). Behind the legacy MCP tools and the GUI.
- **`mcp_server.py`** — `build_server(mode)`. **v2** (default, `ziplex-mcp [--project]`): five live-graph tools over `core.api.Graph` (`graph_overview`, `who_depends_on`, `dependencies_of`, `impacted_tests`, `dependency_path`); `GraphSession` refreshes at most every `REFRESH_INTERVAL` (2s), serializes on one lock, answers `ValueError` as `error: ...` text, waits `INDEX_WAIT` on a cold build. `TOOL_DESCRIPTIONS_V2` + `INSTRUCTIONS_V2` stay under 4,000 chars (`tests/test_mcp_server_v2.py`). **Legacy** (`--aif` / `--legacy-tools`): the ten aif.json tools from `query_service` with `TOOL_DESCRIPTIONS`.
- **`hook.py`** — `ziplex-hook` (PostToolUse): nearest `.ziplex/index.db` above the edited file, path-only refresh (full walk if the index is older than `FULL_REFRESH_AFTER`), one line of dependents/certain tests at most once per (session, file) per 10 minutes, always exit 0.
- **`skill_export.py` / `flat_export.py`** — a pack as a Claude Agent Skill directory / one Markdown file.
- **`freshness.py`** — hash-diff of a saved pack against disk (`check_freshness_scoped()` is the one entry point; `load_pack_scope()` reads back a pack's CLI-only include/ignore); also `load_previous_summaries()` for pack's reuse.
- **`search.py`**, **`tokenizer.py`** (lazy tiktoken from `[llm]`, char-estimate fallback; per-file batched encode), **`tech_stack.py`** (manifest dependency names), **`folder_summary.py`** (structural "Contains N files" per folder), **`text compressors`** live in `extract/text/`.

## CLI, config

`cli.py`: argparse dispatcher (`_build_parser()` + `_cmd_*`, `_COMMANDS`). `ziplex dev <tool>` is an alias for the debug subcommands (collect/tokens/search/detail/signatures/dependencies/api/compress/debug). `config.py`: per-project `.ziplex.json` (`include`, `ignore`, `exclude_flagged_from_graph`); `load_config()` never raises. `settings.py`: per-user `~/.ziplex/settings.json` (LLM provider/model/keys, GUI options), `EDITABLE_FIELDS` shared by the CLI and the GUI Options page. `doctor.py`: environment check, pure `run_diagnostics()`. `progress_i18n.py`: `pick(en, ko)` for progress output (a ContextVar set per pack).
